## Cancellation and saved-connection repairs

The separate provider repair is merged: pre-aborted requests and cancellation
during credential preparation are checked before provider execution, and stopped
work is not sent to a backup. Its reported validation covers 111 host and 23 panel
cases plus the unsigned build. This package did not implement that repair.
Cancellation cannot retract information or allowance already used by a sent request.

The file credential store now follows the pinned engine contract: an undefined
modifier result keeps and returns the saved credential, and only explicit Remove
deletes it. A queued token refresh that finds another request already refreshed
therefore keeps the connection. A host test races two ChatGPT fixture requests
through one refresh; it is protocol-stand-in proof, not a live account check.

## Roadmap, without release promises

1. Complete local publication preparation: current illustrated docs, qualified
   licensing/notices, clean-source installation and exact export review.
2. Only after exact-content approval, establish the protected public project and
   verify its fresh clone and hosted checks.
3. Address remaining native/device and context journeys through separately scoped
   work. A roadmap entry is not a shipped capability or a delivery date.

New integrations, local models, signed releases, paid demos and automatic messaging
are not promised by this publication package.
