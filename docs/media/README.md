The GIF is 960 × 1046 pixels, approximately 0.89 MB and 9.53 seconds. It plays once;
identical captures are coalesced into 53 encoded frames while preserving timing.

equivalent covers the approval and resulting saved state. Blank canvas around a
smaller native window is intentional: bottom/right alignment preserves actual
