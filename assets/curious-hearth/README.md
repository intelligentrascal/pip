# Pip — Curious Hearth

The selected painted appearance, imported as cropped RGBA layers, a
registered silhouette contour and an assembled still fallback. Pip's app code
owns task meaning, verification and any future real listening state. These images
are not evidence of a completed task or active microphone.

`manifest.json` is the project's normalized data-only registration. It records
one logical canvas, pivots, crop offsets/sizes, logical parents, global paint order,
optional facial variants and file integrity. Crop pixels stay at their own size;
scale the complete logical scene, not each tile into a full-canvas texture.

The editable compositing inputs are the individual alpha-masked PNGs plus this
registration. They are raster layers, not editable vector painting or a general
3D rig. Use only bounded front-facing joint motion. The app's static native task
badge uses the assembled still; healthy animated playback uses the actual parts.

The importer deliberately excludes private handoff metadata, executable demos and
demo-only verification/listening controls. It performs no generation, upload or
account operation. The existing authored monochrome menu mark remains in use.
